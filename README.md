# 모아 (Moa Media Organizer)

Windows에서 사진과 영상을 탐색하고, 원본 위치를 유지하면서 앨범과 태그로 정리하는 앱입니다.

## 주요 기능

- 폴더의 사진·영상과 ZIP 내부 사진 탐색, 썸네일과 원본 해상도 미리보기
- 가상 앨범과 태그로 분류, 이름·태그 검색, 날짜·이름·확장자 정렬
- 내장 사진·영상 뷰어, F11 전체 화면과 Esc 복귀
- 실제 폴더 트리, 탐색기에서 파일 위치 열기, 파일 이름 변경 및 이동

ZIP 내부 사진은 읽기 전용으로 표시합니다.

## 실행

1. Windows x64에 Python 3.14 x64를 설치하고 `setup.bat`을 실행합니다.
2. 영상 재생을 위해 libmpv 개발 빌드를 압축 해제하고 `libmpv-2.dll`을 `vendor/mpv/`에 넣습니다. 다운로드 주소와 체크섬은 [외부 구성 요소 안내](THIRD_PARTY_NOTICES.md)에 있습니다.
3. `start.bat`을 실행합니다. 라이브러리와 캐시는 `data/`에 저장됩니다.
