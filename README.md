# 모아 (Moa Media Organizer)

Windows에서 사진과 영상을 탐색하고, 원본 위치를 유지하면서 앨범과 태그로 정리하는 앱입니다.

## 주요 기능

- 폴더의 사진·영상과 ZIP 내부 사진 탐색, 썸네일과 원본 해상도 미리보기
- 최대 2단계 가상 폴더로 앨범 정리, 앨범 추가·제외와 태그로 분류, 이름·태그 검색, 날짜·이름·확장자 정렬
- GIF 애니메이션을 지원하는 사진·영상 뷰어, Space 재생·일시정지, F11 전체 화면과 Esc 복귀
- 실제 폴더 트리, 탐색기에서 파일 위치 열기, 파일 이름 변경 및 이동

ZIP 내부 사진은 읽기 전용으로 표시합니다.

## 실행

1. Windows x64에 Python 3.14 x64를 설치하고 `setup.bat`을 실행합니다.
2. 영상 재생을 위해 libmpv 개발 빌드를 압축 해제하고 `libmpv-2.dll`을 `vendor/mpv/`에 넣습니다. 다운로드 주소와 체크섬은 [외부 구성 요소 안내](THIRD_PARTY_NOTICES.md)에 있습니다.
3. `start.bat`을 실행합니다. 라이브러리와 캐시는 `data/`에 저장됩니다.


## 앨범 폴더와 이미지 배율

- 분류 메뉴의 **새 앨범 폴더**로 폴더를 만들고, 폴더 우클릭의 **하위 폴더 만들기**로 2단계까지 정리합니다.
- 앨범 우클릭의 **앨범을 폴더로 이동**에서 위치를 선택합니다. 폴더도 우클릭으로 이름과 위치를 바꿀 수 있습니다.
- 폴더를 선택하면 하위 앨범의 파일을 중복 없이 모아 보고 검색합니다. 폴더 삭제 시 포함된 앨범은 최상위로 이동합니다.
- 사진·GIF의 기본 표시는 원본 100% 이내의 화면 맞춤입니다. 큰 이미지는 축소하고 작은 이미지는 원본 크기로 표시합니다. 휠과 확대 버튼으로 직접 확대할 수 있습니다.


## 뷰어와 정리 조작

- 사진첩 아이콘은 앨범, 폴더 아이콘은 앨범 폴더입니다. 왼쪽 목록을 우클릭해 앨범이나 폴더를 만들 수 있습니다.
- 앨범·폴더를 다른 앨범 폴더 위로 드래그해 위치를 옮깁니다. 최상위로 옮길 때는 왼쪽 **앨범** 제목 위에 놓습니다. 폴더는 최대 2단계까지 지원합니다.
- 영상은 Space로 재생·일시정지합니다. 음량은 0~100으로 표시하며, 재생이 끝나면 0초에서 일시정지합니다.
- 전체 화면에서는 사진·영상이 화면에 맞춰 표시되고 조작 UI가 겹쳐 나타납니다. 마우스 이동이나 키 입력으로 UI를 표시하며, 약 2.5초간 입력이 없으면 숨깁니다.
